# cmux 관제실 — 메뉴바 미니맵

웹 대시보드(`:7788`)를 맥북 메뉴바에서 보는 Swift 네이티브 앱. 웹은 그대로 두고 **읽기 + 점프**만 한다.

```bash
bash scripts/bundle.sh release && open ./CmuxMinimap.app

# 대시보드가 다른 포트에 있으면 (기본 7788)
CMUXMM_PORT=7801 open ./CmuxMinimap.app --args
```

| 환경변수 | 기본값 | |
|---|---|---|
| `CMUXMM_PORT` | `7788` | 대시보드 포트. **호스트는 열지 않는다** — 루프백을 벗어나는 순간 macOS 로컬 네트워크 권한 대상이 되고, 이 앱이 남의 기계를 들여다볼 이유도 없다 |
| `CMUXMM_POLL` | `5` | 폴링 주기(초) |
| `CMUXMM_DEBUG` | — | `1` 이면 status item 의 `window?.frame` 을 덤프한다 (아래 「메뉴바 포화」 참조) |

## 무엇을 하나
- 메뉴바 배지 = **막힘 N**(`permission` + `question`) — 내가 안 보면 0이 진행되는 것들만 숫자로 센다.
  막힘이 없으면 작업중 수를 초록으로 보여주고, 그것도 없으면 아이콘만.
- 팝오버 = 상태 요약 + **막힘·작업중 목록** + 클릭 시 그 탭으로 점프.
- 목록은 **cmux 그룹**(제품·앱 개발 / 교육·컨설팅 / 인프라·자동화·운영 …)으로 묶는다.
  그룹 순서는 따로 정하지 않는다 — 목록이 이미 `statusOrder` 로 정렬돼 있어서, 그룹이 처음
  나온 순서대로 묶으면 **가장 급한 탭을 가진 그룹이 저절로 위**에 온다.

### 워크스페이스를 어떻게 넣었나
`/api/nav` 의 `group.icon` 은 **SF Symbol 이름이 그대로** 온다(`hammer.fill`,
`graduationcap.fill`, `gearshape.2.fill` …). 변환표 없이 그대로 렌더한다. 실측 9종 전부 실재하는
심볼이었지만, 없는 이름을 넘기면 SwiftUI 가 조용히 빈 자리를 그리므로 존재를 확인하고 쓴다.

워크스페이스 제목은 **탭 제목과 다를 때만** 한 줄 내준다. cmux 는 워크스페이스 제목 앞에 상태
마커(`◐` `✳`)를 붙이므로 그걸 떼고 비교한다 — 안 그러면 같은 말을 두 번 쓴다.
실측 76개 중 25개(33%)가 같아서 생략되고, 나머지 67% 는 탭 제목만으로는 알 수 없던
프로젝트를 알려 준다 — 탭 제목은 직전 대화에서 자동 생성되므로 "통화 전사" 같은 **한 조각**인데,
워크스페이스 이름은 사람이 붙인 것이라 "출판 문서 5종 제작" 같은 **일 전체**를 말한다.

## 판정하지 않는다
상태 판정은 서버 `nav.decide_status` 가 정본이다. 이 앱은 `/api/nav` 가 준 것을 옮겨 담기만 한다.
순서(`statusOrder`)와 '막힘'의 정의(`blockedStatuses`)까지 **서버가 내려 준 값**을 쓴다 —
클라이언트가 상태 집합을 스스로 적으면 정본과 소리 없이 어긋난다(웹의 상태 점 목록이 실제로
`question` 을 빠뜨린 채 돌고 있었다).

## 밟았던 것 — 메뉴바 포화 (2026-09-02)

**앱은 떠 있고 status item 도 있는데 화면에만 없는** 상태를 만났다. 원인은 자리다.

| 실측 | 값 |
|---|---|
| 노치 오른쪽 가용 구간 시작 | `x=848` |
| 기존 아이템 중 최좌단 | `x=882` |
| → 남은 여유 | **34pt** |
| 아이콘+숫자를 따로 둔 status item 폭 | 49pt |

자리를 못 얻은 항목을 macOS 는 조용히 **화면 왼쪽 끝(x=31, 애플 메뉴 옆)** 으로 밀어내고,
앱 메뉴가 그 위를 덮어 완전히 가려진다. 스크린샷으로도 안 보이고 로그도 없다.
찾으려면 `item.button?.window?.frame` 을 직접 찍어야 한다(`CMUXMM_DEBUG=1` 로 켜지는 덤프).

두 가지를 같이 해야 풀린다:
1. **아이콘과 숫자를 한 이미지로 합성**해 폭을 31pt 로 줄인다(`badge(_:count:color:)`).
2. **선호 위치를 명시적으로 요구**한다 — `NSStatusItem Preferred Position <autosaveName>` = 0.
   폭만 줄여서는 여전히 왼쪽에 남았다. 자리를 요구해야 우측(`x=1224`)에 들어갔다.

## 그 밖에
- **.app 번들이 필요한 이유는 권한이 아니라 `LSUIElement`** 다. 이 앱은 자기 status item 만 그리고
  `127.0.0.1` 에만 말을 거니 TCC 도 로컬 네트워크 권한도 필요 없다(루프백은 그 대상이 아니다).
  ad-hoc 서명으로 충분하다.
- **작업중 아이콘은 '동작 줄이기'가 켜져 있어도 멈추지 않는다.** 이 맥은 그 설정이 켜져 있어서,
  끄면 한 번도 안 움직이는 화면이 되고 그건 정지와 구별되지 않는다. 끄는 대신 느리게(2s→4.5s) 한다.
- 색·외관은 **그리는 쪽의 실제 외관**으로 정한다. 전역 시스템 외관으로 칠하면 어긋난다
  (실측: 시스템은 다크인데 팝오버가 라이트로 렌더링됐다).

## 남은 것
- **M2 — 디자인**: `tokens.css` 와 나란히 놓고 색 맞추기, 아이콘 다듬기
- **서버 다운 표시** — 지금은 갱신 실패 문구만 뜬다
- **완료 강조를 여기엔 안 넣었다** — 팝오버는 목록이 짧고 열었을 때만 보여서, 여러 줄이 동시에
  뛰면 과할 것 같았다. 웹 대시보드에만 있다.
